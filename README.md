I’m a fullstack engineer who enjoys turning ideas into products people can actually use.

I work across the stack — from crafting clean, responsive interfaces to designing APIs, databases, authentication, payments, and the systems behind them.

Currently focused on Next.js, TypeScript, Node.js, and modern web architecture, while continuously deepening my understanding of software engineering and computer science.
